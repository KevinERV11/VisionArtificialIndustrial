📌 Descripción general
Este repositorio contiene el desarrollo paso a paso de un sistema de visión artificial industrial utilizando Python y OpenCV.
El objetivo es construir una base sólida para inspección, análisis y procesamiento de piezas industriales.

Incluye scripts, imágenes, datasets sintéticos y miniaturas utilizadas en la serie de vídeos del proyecto.
